# Litesh Nannaware - Portfolio Website

> Inspired by modern cinematic reel portfolio design with interactive video backgrounds, scroll-guided paths, and dynamic case studies.

## 🚀 Live Local Development
The development server is running locally at:
```bash
http://127.0.0.1:5173/
```

To run it again anytime:
```bash
npm run dev
```

To build for production:
```bash
npm run build
```
